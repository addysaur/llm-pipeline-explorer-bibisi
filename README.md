# LLM Pipeline Explorer — BIBISI

An interactive explorer for how LLMs process text, themed **OPSEC LEVEL: BIBISI**.

Type a sentence and watch it move through the pipeline:

- **Tokenisation** — WordPiece-style splitting with `##` subwords and token IDs
- **Embeddings** — a simple embedding view (per-token rows with sparklines, plus a full 16-dimension dossier for any token you select)
- **Plotting** — a rotatable 3D PCA embedding space, a vector bar chart, a 2D PCA scatter plot, and a clickable cosine-similarity heatmap, all synced to the selected token

## The panel

Every run is judged live by animated 3D Pepe + V (Guy Fawkes) figures — they blink, track your pointer, nod, side-eye, and facepalm as the verdict escalates across the tiers, up to:

- `OPSEC LEVEL: BIBISI GQDS WQNNXD` — the chaotic max, Pepe flushes red
- `OPSEC LEVEL: BIWISI` — the secret rival tier: summon it with a flawless clean run, or by typing the word itself

## Run it

Just open `index.html` in a browser — it's a single self-contained file.
