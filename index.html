stage_01 // feed the machine

    
Type a sentence. Get judged.

    
Your sentence runs the full pipeline below — split into tokens, turned into 16-number embeddings, plotted in 3D and cross-compared. The panel scores how cursed the run looks at every step. Everything updates live and stays in sync: tap any token anywhere and it lights up everywhere. Rumour in the chamber: BIBISI has a bleached rival — BIWISI, the opposite verdict. A flawless, shatter-free clean run can summon it… or just speak its name.

    

      

        
        
      

      

        
        
        
        
        
        
      

      

    

  


  
  

    
stage_02 // tokenisation

    
WordPiece split

    
Words the model knows stay whole. Unknown words get chopped into subwords — continuations wear a ## tag. Every piece gets a token ID from the vocab. Dashed chips = subword pieces of a shattered word.

    

      

    

  


  
  

    
stage_03 // embeddings — the numbers room

    
One token. 16 numbers.

    
Each token becomes a vector of 16 numbers — its coordinates in meaning-space. Kept simple on purpose: one quiet row per token with a sparkline of its values. Tap a row to open its file and see all 16 numbers. Do not read them aloud.

    

      

        

      

      

    

  


  
  

    
stage_04 // embedding space

    
Embeddings in 3D

    
The 16 numbers per token get compressed to 3 axes (PCA) and plotted inside the chamber vault. Tokens with similar vectors drift together; weird loners float off on their own — the panel notices those first.

    

      
      
DRAG to rotate · SCROLL / PINCH to zoom · TAP a token chip, row or plot point to select it everywhere.

      

    

  


  
  

    
stage_05 // plotting

    
Read the evidence

    
Three views of the same vectors: the selected token's raw values, where every token lands in 2D, and how similar every pair of tokens is.

    

      

        
Vector bars — selected token

        
All 16 dimensions of the selected token. Green bars reach up (positive), red bars hang down (negative).

        

      

      

        
2D scatter — PCA projection

        
The two strongest axes of variation. Close dots = similar meaning-vectors. Tap a dot to select that token.

        

      

      

        
Cosine similarity — heatmap

        
How alike every token pair is, from −1 (opposite) to +1 (identical direction). Bright green = near-twins. Tap any cell to inspect the pair.
